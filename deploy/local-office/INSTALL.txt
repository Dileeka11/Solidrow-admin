--------------------------------------------------------------
පියවර 1 — Secret token එකක් හදාගන්න
--------------------------------------------------------------
PHP තියෙන PC එකක Command Prompt එකේ (නැත්නම් කොටස 2 පියවර 1න්
XAMPP install කළාට පස්සේ):

    php -r "echo bin2hex(random_bytes(32));"

ලැබෙන අකුරු 64 string එක Notepad එකක save කරගන්න.
මේ guide එකේ <TOKEN> කියලා තියෙන හැම තැනටම මේක දාන්න.
හැම PC එකටම එකම token එක.

!! මේ token එක කාටවත් දෙන්න එපා.


--------------------------------------------------------------
පියවර 2 — Live server එකේ .env එක set කරන්න
--------------------------------------------------------------
  1. cPanel -> File Manager
  2. Settings (උඩ දකුණු පැත්තේ) -> "Show Hidden Files" tick කරන්න
  3. /home/festelsd/registration_app/.env  -> Edit
  4. File එකේ අන්තිමට මේ lines 2 එකතු කරලා Save කරන්න:

    SYNC_ROLE=hub
    SYNC_TOKEN=<TOKEN>

  5. /home/festelsd/registration_app/bootstrap/cache/ folder එකේ
     config.php හෝ routes-v7.php තියෙනවා නම් delete කරන්න.
     (නැත්නම් කමක් නෑ.)


--------------------------------------------------------------
පියවර 3 — Live server එක check කරන්න
--------------------------------------------------------------
Command Prompt එකේ (<TOKEN> replace කරලා):

    curl https://registration.solidrow.lk/api/sync/changes?after=0 -H "Authorization: Bearer <TOKEN>" -H "Accept: application/json"

  {"cursor":... ,"items":[...]} වගේ එකක් ආවොත් -> හරි.
  401 ආවොත් -> token එක වැරදියි.
  404 ආවොත් -> .env එක save වුණාද, cache files delete කළාද ආයෙ බලන්න.

පියවර 1 — Software install කරන්න
--------------------------------------------------------------

  2. Composer                     https://getcomposer.org
     (install කරද්දී PHP path එක C:\xampp\php\php.exe දෙන්න)
  3. Node.js 20 LTS               https://nodejs.org

MySQL එකේ "Autostart" (Service) tick කරන්න, PC එක on කරද්දී auto
start වෙන්න. (Apache ඕනේ නෑ.)

PC එකේ date / time හරියට තියෙන්න ඕනේ:
Settings -> Time & language -> "Set time automatically" ON කරන්න.
(වෙනස්කම් දෙකක් ගැටුනොත් අලුත්ම එක තෝරන්නේ time එකෙන්.)

      -> C:\Solidrow-admin\backend\storage\logs\laravel.log
